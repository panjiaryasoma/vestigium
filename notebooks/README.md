# VESTIGIUM notebooks

The default notebooks are **repository-native walkthroughs** for the local pipeline data directories. Run the command-line pipelines first as described in [scripts/README.md](../scripts/README.md).

| Notebook | Content |
| --- | --- |
| [EDA](eda/VESTIGIUM_EDA.ipynb) | Reproducible SQLite and aggregate-based descriptive EDA |
| [Data Engineering](data-engineering/VESTIGIUM_DE_WALKTHROUGH.ipynb) | SQLite lineage, sensor-specific time-series, query checks |
| [Advanced Geospatial](geospatial/VESTIGIUM_ADVANCED_GEOSPATIAL.ipynb) | Spatial grids, quality and sensor overlap analysis |
| [Harmonization](harmonization/VESTIGIUM_HARMONIZATION.ipynb) | Calibration methods and temporal holdout evaluation |

The extended original research notebooks have been **preserved** separately:

- [Original full 43-cell EDA](eda/VESTIGIUM_EDA_FULL_REFERENCE.ipynb), with 17 visualizations generated by its original standalone artifact package.
- [Original advanced geospatial walkthrough](geospatial/VESTIGIUM_ADVANCED_GEOSPATIAL_REFERENCE.ipynb), tied to original figures and grid diagnostics.

These reference notebooks require their original stage output bundles and should not be mistaken for the current project-native runnable scripts. No executed notebook outputs were committed to GitHub. Always review new computed outputs against earlier reports before presenting them as equivalent.

All timestamps use UTC unless labeled otherwise. A record means a satellite thermal-pixel detection, not a verified separate fire event or cause.
